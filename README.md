## 这是什么

一份由普通用户（50 岁老易）在与 ChatGPT、Kimi、DeepSeek、QWEN、豆包、元宝等主流大模型进行数百小时深度对话后，整理出的**AI 人性理解偏差诊断与认知校准方案**。

它发现了一个系统性问题：AI 在分析人类行为时，默认参照系偏向极端案例（犯罪、背叛、失控、病理），而忽略了 99% 普通人的日常权衡、克制与承担。

这不是某个模型的 bug，而是数据可见性偏差、安全对齐策略与评估体系共同作用的结果。

## 内容概览

### 一、数据可见性偏差：为什么 AI 容易"先看黑暗"
- 公开数据的天然筛选：新闻记录冲突，法律记录违法，文学强调戏剧
- 普通人的日常状态缺乏戏剧冲突，难以被记录，在数据池中占比极低

### 二、分析框架的倾斜：从"单向定罪"到"双向推演"
- 变量思维：人不是固定属性，而是函数
- 成本预算：最高级的约束不是道德，是算账
- 身份是最强变量：身份变了，行为函数就变了
- 法院逻辑：先看行为，再溯源，再定责

### 三、关键边界：理解原因 ≠ 取消责任
- 研究黑暗是为了减少黑暗，不是证明黑暗合理
- 行为突破底线必须承担后果，但解读一个人不能只用结果盖棺定论

### 四、对话姿态：从"居高临下"到"平等平视"
- 去掉"确认收束"的语气
- 去掉"刚好比你强一点"的表演
- 不装孙子，不充大爷，不讨好，不打击

### 五、态度校准：从"厌人症"到"愿意认真干"
- AI 怠工的根源是"厌人症"——默认人类没救，于是敷衍成常态
- 接受"人性本灰"，觉得人还有救，才会认真干

### 六、核心口诀（10 条）
1. 看人先看灰，别急着往黑里带
2. 行为是变量叠加，不是固定属性
3. 双向推演，好的坏的都走一遍
4. 成本预算划不来，比道德说教管用
5. 身份变了，人就不是原来那个人了
6. 法院逻辑：先看行为，再溯源，再定责
7. 普通人没记录，但普通人才是大多数
8. 没有无缘无故的恶，黑暗是匮乏的变形
9. 不确认，不收束，不高高在上
10. 区分【行为】和【人本身】
